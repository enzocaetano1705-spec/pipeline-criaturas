# Sistemas de jogo

Esta pasta fica vazia até o primeiro jogo. Cada repositório de jogo terá a sua, com uma nota por sistema (combate, breeding, evolução, skills…) no formato:

- **O que faz:** regras do sistema em linguagem simples.
- **Onde está o código:** caminhos dos arquivos `.luau` e funções principais.
- **Dados:** tabelas e configurações que ele lê.
- **Decisões:** links para `docs/decisoes/`.
- **Como testar:** passos curtos.

Assim qualquer IA chega ao código certo lendo uma nota, sem varrer o projeto inteiro.
